# YTDown

Download YouTube (and other) videos with a nice to use GUI. It's Powered by [yt-dlp](https://github.com/yt-dlp/yt-dlp), and takes care of installing it and updating it so you don't have to.

The main motivation is letting my non-techie family members download YouTube videos without having to use shady websites with lame ads.

It supports Windows, MacOS and Linux.
